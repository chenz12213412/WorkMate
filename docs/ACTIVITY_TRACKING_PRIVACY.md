# WorkMate 活动采集与隐私边界

## 采集内容

- 键盘：只累计按键次数，不读取或保存键值、字符和输入文本。
- 鼠标：累计左键、右键、中键、滚轮次数和相邻移动距离。
- 鼠标坐标：只在内存中保存最后一个点用于计算距离，计算后丢弃，不写入数据库。
- 前台应用：保存进程名和聚合使用时长。窗口标题只存在于瞬时内存快照，不写入数据库。
- Idle / AFK：通过 `GetLastInputInfo` 获取距离最近输入的时长，不记录输入内容。

## 聚合与写入

- Collector 只更新内存计数器。
- `ActivitySnapshotService` 每 5 秒读取一次计数，每 5 分钟批量更新 Activity Bucket。
- Sleep、Lock 和程序退出时刷新已完成的聚合数据。
- 不按单个键盘或鼠标事件写 SQLite。

## SQLite 中明确不存在的内容

- 具体按键、虚拟键码、字符或实际输入文字。
- 密码、聊天内容、剪贴板内容。
- 鼠标坐标、点击位置或鼠标轨迹历史。
- 窗口标题和网页正文。

数据库只保存计数、时长、分数、作息状态、工作模式和进程名级别的聚合结果。
